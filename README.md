# 👑 موقع مطعم قصر الشرق للمشويات والمأكولات الشرقية (Oriental Restaurant)

موقع ويب متكامل، حديث، متجاوب بالكامل وسريع للغاية لمطعم ومشاوي شرقية فاخرة. صُمم الموقع بأحدث معايير تصميم الويب (Modern UI/UX) وتجربة المستخدم الراقية، مع دعم أصيل للغة العربية والاتجاه من اليمين لليسار (RTL).

---

## 🌟 مميزات الموقع

1. **تصميم شرقي فاخر ودافئ (Royal Oriental Vibe)**:
   - درجات لونية فاخرة: البرغندي الملكي، الذهب الدافئ، والفحم الأندلسي العميق.
   - خطوط عربية حديثة وعريقة (`Cairo` و `Amiri`).
   - مؤثرات حركية ناعمة، ولمعان ذهبي، وتأثير الزجاج المصقول (Glassmorphism).

2. **أقسام الموقع الشاملة**:
   - **الهيدر وشريط التنقل**: مثبت (Sticky Header) مع الخط الساخن وزر حجز فوري وقائمة متجاوبة للموبايل.
   - **القسم الرئيسي (Hero)**: خلفية تصويرية جذابة، شارات ثقة، وعناوين رنانة مع أزرار دعوة لاتخاذ إجراء.
   - **قصة المطعم (About Us)**: سرد ملهم للأصالة مع عدادات إحصائية ديناميكية.
   - **مميزات التجربة (Features)**: إبراز جودة اللحوم البلدية، الشوي على الفحم، والخبز البلدي الساخن.
   - **قائمة الطعام التفاعلية (Interactive Menu)**: مبوبة حسب الأقسام (مشويات، طواجن فخار، مقبلات وشوربات، حلويات شرقية، مشروبات وعصائر) مع إمكانية إضافة الأطباق لقائمة الطلب بنقرة واحدة.
   - **صينية الطلبات السريعة (Quick Order Tray)**: شريط عائم يجمع عدد الأطباق والإجمالي، مع زر فوري لإرسال الطلب بكامل تفاصيله عبر واتساب!
   - **قسم الفروع (Branches)**: تبديل سلس بين فرع القاهرة (التجمع الخامس) وفرع الجيزة (الشيخ زايد) مع خرائط Google Maps مدمجة وأرقام الهواتف ومواعيد العمل.
   - **نموذج حجز الطاولات (Table Reservation)**: نموذج متكامل مع نافذة تأكيد منبثقة (Modal) تتيح إرسال تفاصيل الحجز للمطعم مباشرة عبر واتساب.
   - **آراء الضيوف (Testimonials)**: تقييمات 5 نجوم من الزوار.
   - **الأزرار العائمة (Floating Action Buttons)**: زر واتساب مباشر، زر اتصال بالخط الساخن، وزر الصعود للأعلى.

## 🚀 كيفية تشغيل الموقع

الموقع مبني بتقنيات **Vanilla Web (HTML5 + CSS3 + ES6 JS)** النظيفة بدون أي اعتمادات أو برامج وسيطة:

### الطريقة المباشرة (في ثوانٍ معدودة):
1. ببساطة انقر نقراً مزدوجاً (Double Click) على ملف `index.html`.
2. سيفتح الموقع مباشرة وبكامل وظائفه وتفاعلاته في أي متصفح لديك (Google Chrome, Edge, Safari, Firefox).

### للتشغيل عبر خادم محلي (Local Dev Server - اختياري):
- إذا كنت تستخدم محرر **VS Code**، يمكنك تثبيت إضافة **Live Server** والضغط على `Go Live` في شريط الحالة السفلي.

## ⚙️ دليل التخصيص والتعديل السريع

### 1. تغيير اسم المطعم والخط الساخن ورقم الواتساب:
افتح الملف `js/config.js`، ستجد في بدايته كائناً واضحاً وسهلاً للغاية:
```javascript
const RESTAURANT_CONFIG = {
  restaurantName: "اكتب اسم مطعمك هنا", // مثلاً: "ديوان الشرق"
  restaurantSubName: "للمشويات والمأكولات الشرقية",
  hotline: "19988",                      // رقم الخط الساخن الخاص بك
  whatsappNumber: "201011223344",        // رقم الواتساب بدون علامة + لاستقبال الطلبات
  // ...
};
```
بمجرد حفظ الملف، سيتغير اسم المطعم والخط الساخن في كافة أرجاء الموقع تلقائياً!

### 2. تعديل بيانات الفروع (القاهرة والجيزة أو إضافة فرع جديد):
في نفس الملف `js/config.js`، ستجد مصفوفة الفروع `branches`:
```javascript
branches: [
  {
    id: "cairo",
    name: "فرع القاهرة (التجمع الخامس)",
    address: "شارع التسعين الشمالي...",
    phone: "02 21199881",
    mobile: "010 1122 3344",
    workingHours: "يومياً من 12:00 ظهراً إلى 02:00 بعد منتصف الليل",
    // ...
  },
  // يمكنك تعديل العناوين أو إضافة فرع ثالث للإسكندرية مثلاً!
]
```

### 3. إضافة أطباق جديدة أو تعديل أسعار المنيو:
افتح الملف `js/menu-data.js`، ستجد قائمة الأطباق منظمة بدقة. لإضافة طبق جديد، انسخ النموذج التالي وأضفه للمصفوفة:
```javascript
{
  id: "g7",
  name: "اسم الطبق اللذيذ",
  category: "grills", // grills, tajines, appetizers, desserts, beverages
  price: 250,
  tag: "جديد",
  serves: "تكفي شخصين",
  description: "وصف شهي لمكونات الطبق وطريقة طهيه وتتبيلته.",
  image: "رابط الصورة أو مسارها المحلي"
}
```

### 4. استخدام صورك الخاصة بدلاً من الصور الافتراضية:
1. ضع صور أطباقك في مجلد جديد مثلاً باسم `images/` داخل مجلد المشروع.
2. غيّر قيمة `image` في `js/menu-data.js` أو في `index.html` إلى مسار الصورة، مثل:
   ```javascript
   image: "images/my-kebab.jpg"
   ```

## 🌐 كيفية نشر ورفع الموقع على الإنترنت (Hosting)

الموقع مهيأ تماماً لرفعه مجاناً وبسرعة فائقة:
1. **GitHub Pages**: ارفع مجلد المشروع على مستودع GitHub وفعّل Pages من الإعدادات.
2. **Netlify أو Vercel**: قم بسحب وإسقاط (Drag & Drop) مجلد المشروع وسيعمل فوراً برابط مجاني وشهادة أمان SSL.
3. **الاستضافات التقليدية (cPanel)**: ارفع محتويات المجلد إلى مجلد `public_html` عبر مدير الملفات.
